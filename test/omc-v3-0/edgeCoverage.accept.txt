# --- TARGETS: the predicate exists but its allowed types differ from the schema's -------------
#
# Each is one type in or out, and which side is right is a modelling question rather than a typo:
# whether a Realization can realize a NarrativeAudio, whether a Task can realize one, and whether
# a Provenance Origin may be an AssetStructure.

# --- VERB-UNDECLARED: the definitions use a verb the schema never declares -------------------
#
# hasCxt/cxtFor carry the Context relationship and contributesTo/contributor the credit one. The
# shared edges block has `additionalProperties: true`, so all four validate and no consumer
# notices; the fix is to declare them in the schema. Declaring the Context pair also closes 23 of
# the INVERSE-UNDECLARED findings in edgeInverse.accept.txt.
VERB-UNDECLARED contributesTo
VERB-UNDECLARED contributor
VERB-UNDECLARED cxtFor
VERB-UNDECLARED hasCxt
