# All of these but NOT-INVOLUTIVE are one structural limitation: omcTemplate.inverseEdge()
# answers with a bare predicate name from a flat map, so it can express neither an intrinsic
# inverse nor one a connects group overrides, and two pairs sharing a verb collapse into one
# entry. fMam reads that map to write reverse edges, so what it writes disagrees with the table.
#
# omcTemplate.inverseEdgeFor() closes them: it returns the inverse as an EDGE - name, bucket and
# path - resolved against the domain asked about. The run's REPORT section counts the pairs the
# two disagree on. They stay accepted here because the map is still what fMam reads: it runs
# omc-util 1.5.0, so the switch waits on a release. This file shrinks when fMam has made it.
#
# NOT-INVOLUTIVE is a modelling question about the uses/usedBy/usedIn triangle, not this.
