(static) subscribe(listener) → {function}

Description:

  • Subscribe to cache mutations. The listener is called after any of set, replace, remove, removeWithEdges or reset changes the store.

    The listener takes no arguments — it is a signal that the store moved, not a diff. Read the new state back through exportModel / get / find, and pair with getVersion when a cheap change-token is needed.

Source:
  • src/omcModel/omcSDK.js, line 188
Example
const stop = model.subscribe(() => render(model.exportModel()));
stop();
