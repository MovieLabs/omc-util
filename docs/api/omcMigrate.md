## omcMigrate~omcMigrate(omc, [toSchemaVersion]) ⇒ <code>OmcJson</code>
Migrate either an array of OMC entities a single OMC entity or an object of OMC entities

**Kind**: inner method of [<code>omcMigrate</code>](#module_omcMigrate)  

| Param | Type | Description |
| --- | --- | --- |
| omc | <code>OmcJson</code> | The OMC entity or entities to migrate |
| [toSchemaVersion] | <code>string</code> | Migrate up to this schema version (defaults to latest) |
